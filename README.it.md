## Funzionalità principali

- installazione e configurazione guidate;
- interfaccia di ricezione e diagnostica;
- gestione controllata delle configurazioni;
- log, risoluzione dei problemi e disinstallazione documentati.

## Avvio rapido

```bash
git clone https://github.com/chiaraberti13/OsmoTetraUbuntu.git
cd OsmoTetraUbuntu
chmod +x install.sh
./install.sh
```

Consulta il [manuale completo](docs/manual.it.md) per requisiti, comandi, legenda dell’interfaccia e troubleshooting.

## Uso responsabile

Utilizza il progetto esclusivamente nel rispetto della normativa e su sistemi, hardware e segnali per i quali possiedi un’autorizzazione valida.
