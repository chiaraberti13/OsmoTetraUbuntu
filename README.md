## Key features

- guided installation and configuration;
- reception and diagnostic interface;
- controlled configuration management;
- documented logs, troubleshooting and uninstall flow.

## Quick start

```bash
git clone https://github.com/chiaraberti13/OsmoTetraUbuntu.git
cd OsmoTetraUbuntu
chmod +x install.sh
./install.sh
```

See the [complete guide](docs/manual.en.md) for requirements, commands, the interface legend and troubleshooting.
